# 💊 مدير الصيدلية — تنظيم شغل مدير الفرع

تطبيق في ملف واحد (`index.html`) يعمل على الموبايل والكمبيوتر، بدون إنترنت وبدون تسجيل.

## طريقة التشغيل
- **الأسهل:** افتح ملف `index.html` بالمتصفح (كروم).
- **على الموبايل كتطبيق:** فعّل GitHub Pages للمستودع (Settings ← Pages ← Branch)، افتح الرابط من كروم، ثم «إضافة إلى الشاشة الرئيسية».

## ماذا يحتوي
| القسم | الاستخدام |
|---|---|
| 🏠 الرئيسية | كل المتأخر، والمطلوب اليوم، والقادم خلال 7 أيام، والأوردرات تحت التحضير |
| 📅 الجدول | كل مواعيد الشهر يوماً بيوم، مع التنقل بين الشهور |
| 👥 شؤون العاملين | طلبات الموظفين لشؤون العاملين، وطلبات شؤون العاملين منك، مع تاريخ متابعة |
| 🛒 المشتريات | نواقص، أصناف خاصة لعملاء، مرتجعات، تسعير... مع تاريخ متابعة |
| 📦 الأوردرات | تسجيل وقت الاستلام وزر «جاهز الآن»، ومتوسط وقت التحضير، والمتأخر عن المستهدف، وأداء كل مُحضِّر |
| 📋 الجرد | الجرد الشهري والمفاجئ والثلاجة والجداول: النطاق والقائم بالجرد وقيم العجز والزيادة والصافي، وموعد التسوية، وإجماليات السنة |
| 💰 الخزينة والنقدية | تقفيلة يومية: مبيعات السيستم مقابل النقدي والفيزا والمحافظ والآجل والمصروفات، وحساب العجز والزيادة تلقائياً، ومتابعة توريد النقدية، وتنبيه لو يوم فات من غير تقفيلة |
| 🧾 العهدة والنثريات | المصروفات النثرية، والمتبقي من العهدة، والبنود اللي من غير إيصال، وحالة التسوية |
| 🔧 الصيانة | البلاغات والأولوية والفني والتكلفة والمتابعة |
| 📄 التعاقدات | تاريخ الانتهاء وتنبيه قبله بعدد أيام تحدده |
| ✅ مهام ومتابعات | أي شيء آخر |
| 🧑‍⚕️ الموظفين | قائمة الموظفين (تظهر كاقتراحات في النماذج) |

## المواعيد الثابتة (مضافة جاهزة، ويمكن تعديلها أو إضافة غيرها)
- شيت الإجازات: أيام 10 و 21 و 31 (31 = آخر يوم في الشهر)
- تقييمات الموظفين: من 16 إلى 18
- شيت رواكد المعمل: من 10 إلى 17
- إخراج اكسباير المعمل: من 10 إلى 17
- طلبية المستهلكات: كل ثلاثاء
- تقفيلة المرتبات: من 21 إلى 24

يظل كل موعد «متأخراً» باللون الأحمر حتى تضغط **✔ تم التنفيذ**.

## التذكير والنسخ الاحتياطي
- من الإعدادات: **تنزيل المواعيد لتقويم الموبايل (.ics)**. يضيف المواعيد الثابتة لتقويم الموبايل مع تنبيه في اليوم السابق وصباح يوم الموعد، حتى والتطبيق مغلق.
- البيانات محفوظة داخل المتصفح على نفس الجهاز. صدّر **نسخة احتياطية** كل أسبوع (يذكّرك التطبيق بذلك).
